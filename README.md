# Dead District

Windows FPS · Zombie Defense / Deathmatch

## 시작하기

**[런처 다운로드](https://github.com/scv207/dead-district-releases/releases/latest/download/DeadDistrictLauncher.exe)**

1. `DeadDistrictLauncher.exe` 하나만 다운로드합니다.
2. 런처를 실행하면 최신 버전 확인과 게임 파일 검사·다운로드가 자동으로 진행됩니다.
3. 완료 후 **게임 시작**을 누르면 로비로 들어갑니다.

게임 파일이 없어도 처음부터 설치합니다. 설치된 파일이 누락되거나 손상되면 다음 검사 때 복구합니다.
다음 업데이트도 동일한 런처를 실행하면 받습니다. 중단된 다운로드의 완료된 묶음은 재사용합니다.

- Windows 10/11
- 설치 위치: `%LOCALAPPDATA%/DeadDistrict`
- 새 버전은 별도 폴더에 검증 후 적용하며 기존 게임 파일과 사용자 설정을 보존합니다.
- 인터넷 연결 실패 시 검증된 기존 설치본이 있을 때만 오프라인 실행을 허용합니다.
- 개인 배포 실행파일이며 Windows 코드 서명 인증서는 적용되지 않았습니다.
